# 인앱 카메라 미리보기 설계

## 목적

현재 촬영 화면의 예시 계량기 이미지를 실제 후면 카메라 영상으로 교체한다. 사용자는 시스템 카메라 앱으로 이동하지 않고 방울이 앱 안에서 계량기를 맞추고 촬영하며, 필요할 때 플래시를 직접 켜고 끈다.

## 선택한 방식

Capacitor 8과 호환되는 `@capacitor-community/camera-preview` 8 계열을 사용한다.

- 네이티브 촬영 화면 진입 시 후면 카메라 미리보기를 시작한다.
- 기존 숫자판 정렬 테두리, 안내 문구와 촬영 버튼은 카메라 영상 위 HTML 오버레이로 유지한다.
- 흰 촬영 버튼은 시스템 카메라를 열지 않고 현재 미리보기 프레임을 캡처한다.
- 우측 상단 플래시 버튼은 기기가 지원할 때 `off`와 `torch`를 전환한다.
- 플래시는 계량기 유리 반사를 고려해 기본 꺼짐으로 시작한다.

## 입력 흐름

### 네이티브 카메라

1. 촬영 화면이 열리면 카메라 권한을 확인하고 후면 미리보기를 시작한다.
2. 사용자는 정렬 테두리에 계량기 숫자판을 맞춘다.
3. 플래시 버튼을 누르면 지원 기기에서 손전등을 켜거나 끈다.
4. 촬영 버튼을 누르면 현재 프레임을 JPEG 파일로 변환한다.
5. 미리보기와 플래시를 종료하고 기존 `POST /meter/scan` 흐름으로 파일을 전달한다.

### 갤러리와 웹

- 네이티브 갤러리 버튼은 현재 `@capacitor/camera` 사진 선택 기능을 유지한다.
- 갤러리를 여는 동안 미리보기를 정지하고, 취소 후 촬영 화면으로 돌아오면 다시 시작한다.
- 웹 개발 환경은 실제 네이티브 미리보기 대신 기존 파일 입력과 `capture="environment"` 폴백을 유지한다.

## 수명 주기와 오류 처리

- 촬영 화면 닫기, 직접 입력 이동, 사진 선택, 촬영 완료와 컴포넌트 해제 시 카메라를 정지한다.
- 카메라 정지 시 플래시도 꺼진 상태가 되도록 정리한다.
- 카메라 권한 거절과 미리보기 시작 실패는 촬영 화면 안에서 안내하고 직접 입력과 갤러리 선택은 계속 제공한다.
- 플래시 미지원 기기에서는 플래시 버튼을 비활성화하고 촬영 자체는 허용한다.
- 중복 탭으로 촬영 또는 미리보기가 두 번 시작되지 않도록 진행 상태를 제어한다.

## 변경 범위

- `frontend/package.json`과 lock 파일에 Camera Preview 플러그인을 추가한다.
- `frontend/android/app/src/main/AndroidManifest.xml`에 카메라 권한을 명시한다.
- `frontend/src/camera.js`에 미리보기 시작·정지·촬영·플래시 어댑터를 추가한다.
- `frontend/src/components/CameraFlow.jsx`를 실제 미리보기 수명 주기와 연결한다.
- 기존 `@capacitor/camera`는 갤러리 선택과 웹 폴백을 위해 유지한다.
- 백엔드 스캔 API와 모델 코드는 변경하지 않는다.

## 검증 기준

- 네이티브 촬영 화면 안에 후면 카메라 영상이 표시된다.
- 흰 촬영 버튼이 시스템 카메라 앱을 열지 않고 인앱 프레임을 촬영한다.
- 플래시 버튼이 기본 꺼짐에서 `torch`를 토글하고 종료 시 꺼진다.
- 갤러리 선택, 취소, 직접 입력과 서버 전송 흐름이 유지된다.
- Node 계약 테스트, Vite 빌드, Capacitor sync와 Gradle Debug APK 빌드가 통과한다.
- Android 실기기에서 미리보기, 촬영, 플래시, 갤러리 복귀를 확인한다.

## 제외 범위

- 자동 플래시 판단, 줌, 전·후면 카메라 전환과 동영상 촬영은 추가하지 않는다.
- iOS 프로젝트 생성과 실기기 검증은 이번 작업에 포함하지 않는다.
