# 상점 상품명 교정 설계

## 목적

상점에 노출되는 오탈자와 낯선 외래어를 사용자가 바로 이해할 수 있는 상품명으로 교정한다.

## 변경 범위

| 현재 상품명 | 교정 상품명 | 근거 |
|---|---|---|
| 튜립 화분 | 튤립 화분 | 표준 외래어 표기 교정 |
| 하트 쿼션 | 하트 쿠션 | 오탈자 교정 |
| 원목 서람장 | 원목 서랍장 | 오탈자 교정 |
| 별빛 오토만 | 별빛 의자 | 일반 사용자에게 익숙한 표현 사용 |
| 리본 갈랜드 | 리본 가랜드 | 국내에서 더 널리 쓰이는 표기 사용 |
| 민트 스툴 | 민트 스툴 | 가구 상품명으로 일상적으로 사용되므로 유지 |

## 구현 원칙

- `frontend/src/components/ShopScreen.jsx`의 화면 표시용 `name`만 변경한다.
- 상품 ID, 가격, 이미지 경로, 크기, 구매·장착·배치 동작은 변경하지 않는다.
- 기존 상점 데이터 계약 테스트에 상품명 교정 항목을 추가한다.

## 성공 기준

- 상점 데이터에서 다섯 개 상품명이 교정된 문자열로 노출된다.
- 기존의 잘못된 다섯 문자열은 소스에 남지 않는다.
- `민트 스툴`은 그대로 유지된다.
- 전체 Node 테스트와 Vite 프로덕션 빌드가 통과한다.
