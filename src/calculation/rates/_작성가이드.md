# 지역별 요금표 작성 가이드

`_TEMPLATE.json`을 복사해서 **지역 한 곳당 파일 한 개**를 만들어 채웁니다.
파일 이름은 영문 소문자로: `seoul.json`, `busan.json`, `gyeonggi.json` …

> 모든 칸은 JSON이라 **주석을 못 답니다.** 헷갈리면 이 문서를 보세요.
> 숫자는 따옴표 없이(`360`), 빈칸은 `null` 그대로 두지 말고 **반드시 실제 값으로 교체**하세요.

---

## 1. 어디서 찾나
- **상수도·하수도 단가** → 해당 시·도 **수도조례 / 하수도 사용 조례**의 "요금표" 별표.
  (자치법규정보시스템 elis.go.kr 또는 각 시 상수도사업본부 홈페이지 → 요금안내)
- **물이용부담금 단가** → 환경부 고시. 수계별로 다름(지자체 무관).
- `출처` 칸에 조례명·시행일·URL을 꼭 적어주세요 (나중에 검증·업데이트용).

## 2. 칸 설명

| 칸 | 뜻 | 예시 |
|---|---|---|
| `지역` | 지자체 이름 | `"서울특별시"` |
| `수계` | 4대강 권역 중 하나 | `"한강"` |
| `부가세_적용` | 상하수도요금에 부가세 붙는지 | 대부분 `false` (면세). 붙으면 `true` |
| `물이용부담금_단가_원` | ㎥당 단가 | `170` |
| `기본요금_원` | **계량기 구경별** 정액 기본요금 | `{"13mm": 1080, "20mm": 3000, ...}` |
| `사용요금_구간` | **누진 구간표** (아래 3번) | |

## 3. `사용요금_구간` 채우는 법 (제일 중요)

구간은 **사용량 누진제**예요. 각 칸의 `상한_㎥`은 **그 구간의 윗쪽 경계**입니다.
**마지막 구간의 `상한_㎥`은 항상 `null`** (그 이상 전부) 로 둡니다.

예) 조례에 이렇게 적혀 있으면:
```
0 ~ 30㎥      : 360원
31 ~ 50㎥     : 550원
50㎥ 초과     : 790원
```
→ JSON은:
```json
"사용요금_구간": [
  { "상한_㎥": 30,   "단가_원": 360 },
  { "상한_㎥": 50,   "단가_원": 550 },
  { "상한_㎥": null, "단가_원": 790 }
]
```
- 구간 개수는 지역마다 달라요. **조례에 있는 만큼 줄을 늘리거나 줄이세요.**
- 단일 단가(누진 없음)면 `[{ "상한_㎥": null, "단가_원": 800 }]` 한 줄만.

## 4. 용도(`용도별`)
기본은 `가정용 / 일반용 / 욕탕용` 3개. 조례에 `공업용`, `대중탕용` 등이 더 있으면
같은 형식으로 블록을 추가하면 됩니다. 우리 앱이 안 쓰는 용도는 빼도 돼요.

## 5. 다 채운 뒤
JSON 문법 깨졌는지 확인하려면 이 폴더 상위에서:
```
python engine.py rates/seoul.json 가정용 13mm 20
```
숫자가 나오면 양식 OK. 빨간 에러가 나면 쉼표·따옴표·괄호를 확인하세요.

지역마다 최소 계량기 구경이 `13mm` 또는 `15mm`로 다릅니다. 앱이나 테스트에서
대표 구경을 자동 선택하려면 `auto`를 넣어도 됩니다.
```
python engine.py rates/seoul.json 가정용 auto 20
```

전체 요금표를 한 번에 점검하려면 `bill_calc` 폴더에서:
```
python validate_rates.py
python validate_rates.py --strict
```
`--strict`는 경고도 실패로 처리하므로 제출 전 최종 검수에 쓰면 됩니다.
